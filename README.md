# DSA Visualiser

An interactive web application built with React and TypeScript to visualize fundamental Data Structures and Algorithms (DSA) in real time. This tool helps learners and educators better understand how algorithms work through step-by-step graphical animations.

## Features

- Visualizations for Sorting Algorithms (e.g., Bubble Sort, Merge Sort, Quick Sort)
- Step-by-step animation of algorithm operations
- Adjustable speed and array size
- Built with HTML, CSS, JavaScript, Data Structures and Algorithms principles.
- Clean, responsive, and minimal UI/UX
